# 🧠 AI × Web3 概念闪卡测验工具

> Week 1 可交互 AI 学习产物

---

## 一、它解决什么学习问题？

**问题**：Week 1 学习了 20+ 个 AI 和 Web3 概念（LLM、Prompt、Agent、Wallet、Gas 等），但容易遗忘或混淆。

**解决方案**：创建一个**交互式测验工具**，通过**主动回忆**（Active Recall）巩固记忆：
- 看到问题 → 尝试回忆 → 查看答案 → 确认是否理解
- 比被动阅读笔记更有效

---

## 二、用户如何与它交互？

### 运行方式

```bash
python3 quiz.py
```

### 交互流程

```
1. 启动程序 → 显示主菜单
2. 选择模式 → 随机测验 / 按类别浏览 / 搜索概念
3. 看到问题 → 尝试回忆
4. 按回车 → 查看答案、例子、误区
5. 确认是否理解 → 继续下一个
6. 完成后 → 显示测验结果
```

## 三、输入输出示例

### 示例 1：随机测验

**输入**：选择"1. 随机测验"

**输出**：
```
────────────────────────────────────────────────────
📚 概念：LLM [AI]
────────────────────────────────────────────────────

❓ LLM（大语言模型）是什么？它能做什么，不能做什么？

💡 提示：想想一个读过很多书但从没实践过的人

你的理解（按回车查看答案）：

✅ 答案：LLM 是读过海量文本的'超级接话王'——它不真正理解你说的话，
   但能根据训练数据猜出最合理的回答。

📝 例子：问 Claude '什么是比特币？'，它基于训练时读过的无数文章拼出回答。

⚠️ 误区：LLM 会'一本正经地胡说八道'（hallucination）。

🎯 关键点：LLM 是模式匹配，不是真正理解
```

## 六、限制和改进方向

### 当前限制
1. 知识库是静态的，不会自动更新
2. 没有记录用户的学习进度
3. 没有根据答错的概念进行针对性复习
4. 没有图形界面，只有命令行

### 改进方向
1. 添加学习进度追踪（记录哪些概念已掌握）
2. 添加错题本功能（自动收集不理解的概念）
3. 添加难度分级（基础/进阶/挑战）
4. 开发网页版本（更友好的用户界面）
5. 接入 AI API，动态生成新的测验问题
