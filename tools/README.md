# 🧠 AI × Web3 概念闪卡测验工具

> 一个帮助学习 AI 和 Web3 基础概念的交互式测验工具

---

## 这个工具解决什么问题？

**学习问题**：Week 1 学习了 20+ 个 AI 和 Web3 概念，但容易遗忘或混淆。

**解决方案**：通过**主动回忆**（Active Recall）的方式巩固记忆：
- 看到问题 → 尝试回忆 → 查看答案 → 确认是否理解
- 比被动阅读笔记更有效

---

## 如何使用

### 运行方式

```bash
python3 quiz.py
```

### 功能菜单

1. **随机测验**（推荐）：随机抽取概念进行测验
2. **按类别浏览**：分别查看 AI 概念或 Web3 概念
3. **搜索概念**：输入关键词查找相关概念
4. **查看所有概念**：显示所有概念列表
5. **退出**

## 输入输出示例

### 示例 1：随机测验

```
────────────────────────────────────────────────────
📚 概念：LLM [AI]
────────────────────────────────────────────────────

❓ LLM（大语言模型）是什么？它能做什么，不能做什么？

💡 提示：想想一个读过很多书但从没实践过的人

你的理解（按回车查看答案，输入 'skip' 跳过）：

✅ 答案：LLM 是读过海量文本的'超级接话王'——它不真正理解你说的话，但能根据训练数据猜出最合理的回答。

📝 例子：问 Claude '什么是比特币？'，它基于训练时读过的无数文章拼出回答。

⚠️ 误区：LLM 会'一本正经地胡说八道'（hallucination）。

🎯 关键点：LLM 是模式匹配，不是真正理解
```

## 限制和改进方向

### 当前限制
1. 知识库是静态的，不会自动更新
2. 没有记录用户的学习进度
3. 没有根据答错的概念进行针对性复习
4. 没有图形界面，只有命令行

### 改进方向
1. 添加学习进度追踪（记录哪些概念已掌握）
2. 添加错题本功能（自动收集不理解的概念）
3. 添加难度分级（基础/进阶/挑战）
4. 开发网页版本（更友好的用户界面）
5. 接入 AI API，动态生成新的测验问题
