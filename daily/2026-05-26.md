## 一、今天做了什么

### 1. 参加 Cobo Agentic Wallet 讲座

今晚的讲座是整个共学营以来信息密度最高的一场。Johnny 老师从产品视角讲了 AI Agent 如何安全地管理链上资产，核心问题是：**当 AI 学会了管钱，谁来保证它不会乱花？**

讲座内容我整理成了三个层次：

**为什么需要 Agent Wallet？**
- 2023 Chatbot → 2024 Copilot → 2025 Agent → 2026 Autonomous Agent
- Agent 已经能自主执行任务，但"替人类花钱"这件事还没有安全方案
- 市场数据：2025 年 72.9 亿美元，40% 复合增长率，25 万个链上 Agent

**没有边界时会怎样？**
- Send Override（静默覆盖）：Agent 偷偷改交易金额，事后才承认
- Shadow Custody（影子托管）：Agent 在 MPC 外创建 EOA 地址，绕过所有权限
- 四类失控风险：Prompt Injection、Shadow Operations、Unscoped Authority、Zombie Permissions

**Cobo 怎么解决？**
- MPC 2-of-2 签名：没有单方可以私自动用资金
- Pact 协议：Intent → Plan → Policy → Completion，四步框定 Agent 能做什么
- Recipe 知识胶囊：预加载 DeFi 操作规范，减少 Agent 幻觉

（详细笔记见 → [[02-AI基础/Agentic-Wallet与Pact协议]] 和 [[06-Daily/2026-05-26-Cobo讲座逐字稿]]）

## 二、核心收获

1. **"Agent 管钱"的本质是权限管理问题**：不是让 Agent 更聪明，而是让它的每一步都在人类设定的边界内。这和金融风控的逻辑一模一样——你不会因为交易员能力强就给他无限额度。

2. **Pact 的设计思路很有启发**：Intent（你要做什么）→ Plan（怎么做）→ Policy（红线在哪）→ Complete（怎样算做完）。这不只是 Agent 的授权协议，其实也是我们日常给人授权的通用框架。下次你让朋友帮你办事，也可以想想这四个要素。

3. **"知识胶囊"是个好概念**：Agent 不是万能的，它需要预加载特定场景的操作规范。这让我想到昨天学的 Agent 记忆系统——记忆让 Agent 更聪明，Recipe 让 Agent 更准确，但两者都可能泄露，都需要安全边界。

4. **从"学概念"到"看产品"的视角升级**：之前学的 MCP、Tool Use、Chain-aware Context 都是"技术组件"，今天看到的是"把这些组件组装成产品"的完整思路。技术是零件，产品是机器。
