# 📝 部署最小智能合约：操作指南

> 用 Remix IDE 在 Sepolia 测试网部署 SimpleStorage 合约

---

## 准备工作

- ✅ MetaMask 已安装，已切换到 Sepolia 测试网
- ✅ 测试钱包有 Sepolia ETH（之前从 Faucet 领过）
- ✅ Chrome 浏览器

---

## Step 1：打开 Remix IDE

1. 打开浏览器，访问：**https://remix.ethereum.org**
2. 等待页面加载完成（Remix 是在线 IDE，不需要安装）

---

## Step 2：创建合约文件

1. 左侧文件浏览器，点击 `contracts` 文件夹
2. 右键 → `New File`
3. 命名为 `SimpleStorage.sol`
4. 把下面的合约代码粘贴进去：

```solidity
// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract SimpleStorage {
    
    uint256 private storedNumber;
    
    event NumberChanged(address indexed setter, uint256 oldValue, uint256 newValue);
    
    function set(uint256 _number) public {
        uint256 oldValue = storedNumber;
        storedNumber = _number;
        emit NumberChanged(msg.sender, oldValue, _number);
    }
    
    function get() public view returns (uint256) {
        return storedNumber;
    }
}
```

---

## Step 3：编译合约

1. 点击左侧第三个图标（⚡ 形状，Solidity Compiler）
2. 确认 Compiler 版本是 `0.8.x`（和代码里的 `pragma` 一致）
3. 点击 **Compile SimpleStorage.sol**
4. 看到绿色勾 ✓ 表示编译成功

---

## Step 4：部署到 Sepolia 测试网

1. 点击左侧第四个图标（以太坊 logo，Deploy & Run Transactions）
2. **Environment** 选择 `Injected Provider - MetaMask`
   - 这时 MetaMask 会弹出连接请求，点击"连接"
3. **Contract** 选择 `SimpleStorage`
4. 点击 **Deploy**
5. ⚠️ **MetaMask 弹出确认框**：
   - 看到的是"Contract Deployment"
   - 确认网络是 Sepolia
   - 确认 Gas 费合理
   - 点击 **确认**

---

## Step 5：查看合约地址

1. 部署成功后，左下角会出现一个绿色区域
2. 显示 `simpleStorage at 0x...` — 这就是你的**合约地址**
3. 复制这个地址

---

## Step 6：在 Etherscan 上验证

1. 打开 **https://sepolia.etherscan.io**
2. 粘贴你的合约地址，搜索
3. 你应该能看到：
   - 合约创建交易
   - 合约地址
   - 创建者地址（你的钱包地址）
   - 区块号和时间

---

## Step 7：调用读取函数（免费）

1. 回到 Remix，展开已部署的合约（左下角）
2. 找到 `get` 按钮，点击
3. 返回值应该是 `0`（因为还没设置过任何数字）
4. ⚠️ **注意**：这一步不需要 MetaMask 签名，因为是"读取"操作，完全免费

---

## Step 8：调用写入函数（需要签名 + Gas）

1. 在 `set` 输入框里输入一个数字，比如 `42`
2. 点击 `set` 按钮
3. ⚠️ **MetaMask 弹出确认框**：
   - 看到的是调用合约的交易
   - 确认 Gas 费合理
   - 点击 **确认**
4. 等待交易确认（几秒到几十秒）

---

## Step 9：验证写入结果

1. 再次点击 `get` 按钮
2. 返回值应该是 `42`
3. 去 Etherscan 查看你的合约地址，应该能看到新的交易记录

---

## 你需要提交的材料

完成以上步骤后，请收集以下信息：

1. **合约地址**：`0x...`（从 Remix 左下角复制）
2. **Etherscan 链接**：`https://sepolia.etherscan.io/address/你的合约地址`
3. **读取结果**：`get()` 返回 `0`（初始值）或 `42`（设置后）
4. **写入交易哈希**：`0x...`（从 MetaMask 或 Etherscan 获取）
5. **代码文件**：我已经帮你存到 GitHub 仓库的 `contracts/SimpleStorage.sol`

---

## 哪些步骤需要人工确认？

| 步骤 | 需要人工确认？ | 为什么 |
|------|--------------|--------|
| 编译合约 | ❌ 不需要 | 只是代码编译，不涉及链上操作 |
| 连接 MetaMask | ✅ 需要 | 授权 Remix 访问你的钱包 |
| 部署合约 | ✅ 需要 | 这是一笔链上交易，需要签名 + Gas |
| 调用 `get()` | ❌ 不需要 | 只读操作，免费，不修改链上状态 |
| 调用 `set()` | ✅ 需要 | 写入操作，需要签名 + Gas |
| 查看 Etherscan | ❌ 不需要 | 只是查看公开信息 |

---

## 理解写入 vs 读取

```
写入操作（set）
├── 修改链上状态
├── 需要交易
├── 需要钱包签名
├── 需要 Gas 费
├── 有交易哈希
└── 可以在 Etherscan 上看到

读取操作（get）
├── 不修改链上状态
├── 不需要交易
├── 不需要钱包签名
├── 不需要 Gas 费（免费）
├── 没有交易哈希
└── 只是查询，不记录在链上
```

这就是智能合约的核心区别：**写入 = 改变世界状态 = 需要共识 = 需要成本；读取 = 查看世界状态 = 不需要共识 = 免费。**
